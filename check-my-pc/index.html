1Quick check (one click)

Press the button and your browser tells us what it is allowed to share: your graphics chip and roughly how much memory you have. This is a first guess, not the final answer.

2Full check (about a minute)

For an exact answer, Windows can describe your PC itself. This command only reads information (using Windows' own built-in tools). It does not change, install or send anything. It copies the details to your clipboard so you can paste them here.

It reads: processor name and cores, motherboard maker and model, each memory stick's size, speed and type, total memory slots and the board maximum, graphics card name and memory, Windows version, whether it is a laptop, and free space on drive C:. Then it formats that as text and copies it.

Step by step

  1. Press the orange Copy command button above.
  2. Right-click the Windows Start button (the Windows logo, bottom left or bottom middle of your screen).
  3. Click Terminal (Windows 11) or Windows PowerShell (Windows 10). Either one is fine, including an "Admin" window (you do not need Admin).
  4. A window with text opens. Right-click inside it (or press Ctrl + V) to paste. If Windows asks about pasting multiple lines, click Paste anyway.
  5. Hit Enter to continue. After a few seconds it says "Done! Your results are copied."
  6. Come back to this page, click in the box below, and press Ctrl + V. Then press Check my results.

Not comfortable with PowerShell? Use System Information instead
  1. Press the Windows key, type msinfo32 and press Enter. System Information opens. It only shows information.
  2. On the first page, find Installed Physical Memory (RAM) (for example "16.0 GB") and Processor.
  3. On the left, open Components > Display. Note the Name of each graphics adapter. (Windows often shows graphics memory wrong here; leave the memory box empty if unsure and we will estimate it from the name.)

How we decide: a model fits "fast" when its size plus about 1.5GB fits in your graphics card memory, and "works, slower" when it fits in your regular memory after leaving about 4GB for Windows. These are widely used rules of thumb, not guarantees. Real speed also depends on your processor and memory speed.

Before you buy a graphics card: check your power supply

Windows cannot see your power supply, so we cannot check it for you. It takes two minutes:

  1. Shut down the PC and unplug it.
  2. Remove the side panel (usually two screws at the back).
  3. Find the metal box where the power cord plugs in. Its sticker lists a number with a W, like 500W. That is the wattage.
  4. Look for spare cables labelled PCIe or PCI-E (6+2 pin). Most cards need one.

Common questions

Is the Check My PC tool safe?

Yes. Nothing is downloaded or installed. The quick check only reads what your browser already shares. The full check is one read-only Windows PowerShell command that uses Windows' own Get-CimInstance to read your hardware details and copy them to your clipboard. It changes nothing. Everything is worked out inside your browser and nothing is uploaded.

Why can't the website see all my hardware?

Browsers hide most hardware details on purpose, for your privacy. For example, browsers never report more than 8GB of memory. That is why the quick check is only a first guess and the full check asks you to run one command and paste the result.

How much memory do I need to run AI on my own PC?

Roughly, a model needs about its download size plus 1 to 2GB, either in graphics card memory (fast) or in regular memory (slower). 8GB runs small 3B models, 16GB runs 8B models, and 32GB or a 12GB graphics card handles 12B to 14B models comfortably. These are approximations.

I am not comfortable with PowerShell. Is there another way?

Yes. Press the Windows key, type msinfo32 and press Enter. System Information shows your memory, processor and graphics card. Type those numbers into the manual boxes on this page.

Can you tell me my power supply wattage?

No. Windows cannot read the power supply. Look at the sticker on the side of the power supply inside your PC (unplug first) for a number like 500W. We list the minimum wattage for each suggested graphics card.
