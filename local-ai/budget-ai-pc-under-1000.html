You do not need a $5,000 “AI workstation” to run helpful local chat and light coding help on Windows. You need enough RAM, decent storage, and realistic model choices (see 16GB model guide). This page is framed as good enough for local chat/code help, not training foundation models.

Build vs buy mini-PC

Buy a mini-PC (fastest path)

  • Pros: Quiet, small, low power, fewer compatibility headaches.
  • Cons: RAM sometimes soldered; GPU upgrades limited or impossible.
  • Target: 32GB RAM configs when the budget allows; 16GB works if you stick to 7B–8B models.

DIY / tower build

  • Pros: Swap RAM/GPU later; used GPU market can be a steal.
  • Cons: Time, cable management, PSU sizing, more ways to mis-order parts.

Rule of thumb: If you’ve never built a PC, buy a mini-PC or a simple prebuilt with upgradeable RAM. Spend brainpower on Ollama + Open WebUI, not debugging boot loops.

Parts list bands under $1,000

Prices move, treat these as budget bands, not a static cart.

Path 1: Mini-PC ready (~$500–$900)

  • Mini-PC with modern AMD/Intel CPU
  • 32GB RAM preferred (16GB minimum)
  • 512GB–1TB NVMe
  • Optional: USB SSD for model overflow

Outcome: solid Tier A/B local chat; quiet enough for a desk or shelf.

Path 2: Upgrade the PC you own (~$80–$400)

  • 32GB RAM kit matched to your laptop/desktop
  • 1TB NVMe if storage is full/slow
  • Skip GPU until RAM and disk are healthy

Often the best ROI, don’t buy a new box if RAM was the bottleneck.

Path 3: Tower + used GPU (~$700–$1,000 all-in)

  • Modest used/refurb CPU + B-series / mid chipset board
  • 32GB DDR4/DDR5
  • 1TB NVMe
  • Used GPU with 8GB+ VRAM (watch PSU watts and case clearance)
  • Decent 550W+ known-brand PSU if adding GPU

Outcome: faster tokens/sec on 7B–14B models; still not a 70B playground.

What “good enough” means

  • Private drafts, brainstorming, rewrite help, basic coding Q&A.
  • Offline-capable once models are downloaded.
  • Not realtime 4K video generation or training giant models.
