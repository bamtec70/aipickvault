The rule of thumb

Ollama's default downloads are 4-bit quantized (usually Q4_K_M). At that level a model needs roughly 0.6GB of memory per billion parameters, plus extra for the context window (the KV cache) and whatever else your computer is doing.

  • Model file size: listed on each model page at ollama.com/library.
  • Add 1GB to 3GB for context at default settings. Long contexts (32K tokens and up) can add several more GB.
  • Leave 4GB to 6GB free for Windows, your browser, and Open WebUI if the model is running from system RAM.

RAM vs VRAM: which one matters?

VRAM is the memory on your graphics card. If the full model fits there, you get fast replies, often several times faster than CPU only. If it does not fit, Ollama splits the model between GPU and system RAM. That still works, but speed drops toward CPU levels as more of the model spills over.

System RAM is the fallback and the only option on most laptops and mini PCs without a discrete GPU. Here, memory bandwidth sets your speed. Dual channel DDR5 is fine for 7B to 8B models and slow for 30B dense models. Machines with wide unified memory (Apple silicon, AMD Ryzen AI Max) sit in between and can hold much bigger models.

How to check what your model is actually using

  1. Run a model: ollama run qwen3:8b
  2. In a second terminal, run ollama ps. The PROCESSOR column shows 100% GPU, 100% CPU, or a split like 48%/52% CPU/GPU.
  3. A split means the model does not fit in VRAM. Pick a smaller model or a smaller quantization, or shorten the context.

FAQ

How much RAM do I need for Ollama?

16GB is the practical minimum for 7B to 8B models like llama3.1:8b or qwen3:8b. 8GB works only for small 3B to 4B models. 32GB lets you run 14B to 30B class models.

Can Ollama run with 8GB RAM?

Yes, with small models such as qwen3:4b (about 2.5GB download). Close your browser tabs, and expect slower replies than on a GPU.

How much VRAM do I need for a 7B or 8B model?

About 8GB of VRAM fits a 4-bit 8B model with a normal context window. 6GB cards will usually split it between GPU and CPU.

How much memory do I need for a 70B model?

A 4-bit 70B model like llama3.3:70b is about a 43GB download, so plan on 64GB of system or unified memory, or 48GB of combined VRAM across GPUs.

Does Ollama use RAM or VRAM?

Both. It loads as much of the model as fits into GPU VRAM and runs the rest from system RAM. Run ollama ps to see the split.
